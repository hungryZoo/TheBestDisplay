# 총 망라까지 남은 일

- 목적: "디스플레이 옵션에 관한 모든 기능 망라"에 이르기까지 남은 작업을 항목별로 정리. 각 항목의 막힌 이유, 필요한 것, 진행 방법, 완료 판정을 기록
- 기준 시점: v1.0.0 릴리스 뒤 T65 (2026-11-11)
- 현황: 기능 대조표(`docs/COVERAGE.md`) 58행 중 구현 51행, 부분 4행, 미구현 3행. TC 127건 중 통과 121건, 미실행 1건, 보류 5건
- 구분: (가) 사용자 재석만 있으면 가능, (나) 장비 필요, (다) 조사 뒤 판단, (라) 제외 결정 유지, (마) 대조표 밖의 참고 제품 기능

## 1. 요약

| 구분 | 건수 | 내용 |
| --- | --- | --- |
| (가) 사용자 재석 | 4 | 화면이 바뀌는 시험과 관리자 인증이 필요한 시험 |
| (나) 장비 | 6 | HDMI 직결, DDC 지원 모니터, DSC 지원 디스플레이, 언더스캔 지원 디스플레이, HDR 미선언 디스플레이, 측정 장비 |
| (다) 조사 뒤 판단 | 3 | 오버라이드 키, DSC PPS의 자료 출처, 색 관리 밖 출력의 채도 |
| (라) 제외 유지 | 3 | 8K 초과 가상 디스플레이, EDID 장치 쓰기, DSC 강제 |
| (마) 대조표 밖 | 11 | 참고 제품의 최신 기능 중 대조표에 없는 것 |

## 2. (가) 사용자 재석만 있으면 가능

화면이 바뀌므로 실행 직전에 알리고 사용자가 자리에 있을 때 실행.

| 번호 | 항목 | 절차 | 완료 판정 |
| --- | --- | --- | --- |
| A-1 | HDR 선언 추가의 실제 적용 (TC-EDO-008, 대조표 13행) | `tbdctl edid external patch remove-hdr,add-hdr:600 --apply`, `tbdctl hdr external`, `tbdctl edid external reset` | 편집본 적용 뒤 시스템이 HDR 지원으로 인식. 해제 뒤 원본 EDID와 HDR 상태 복귀. 통과하면 13행을 구현으로 변경 |
| A-2 | 전체 통합 테스트 재실행 | `scripts/test.sh` | T59 이후 추가분(T60-T65)을 포함해 전체 통과 |
| A-3 | 다단계 스케일 해상도 5개 일괄 등록의 실제 설치 | 해상도 탭의 일괄 추가 (관리자 인증), `tbdctl reinit external`, 삭제 | 5단계 모드가 목록에 출현, 삭제 뒤 제외. 한도(6144 x 4320)를 넘는 항목이 무시되는지 함께 확인 |
| A-4 | 앱 조작으로만 확인되는 동작 | 결합 밝기와 채도의 조절 막대, 최대 휘도 기준값 비우기, 설정 창의 업데이트 토글, Homebrew 설치본에서 업데이트 창의 예 | 각 동작이 명령과 같은 결과. 자동 조작 도구로는 조절 막대를 움직일 수 없어 직접 조작 필요 |

## 3. (나) 장비 필요

| 번호 | 항목 | 필요한 장비 | 진행 방법 | 대조표, TC |
| --- | --- | --- | --- | --- |
| B-1 | HDMI 직결 링크 정보, HDMI HDCP, 내장 HDMI 포트 DDC | HDMI 포트에 직접 연결한 디스플레이 (HDMI 2.1 권장) | `tbdctl link`, `ports`로 FRL 링크 자료 배치와 HDCP 값 실측. `IOAVService`의 I2C 주소로 DDC 응답 실측 (주소가 다르면 `DDCService`에 경로 추가) | 22행, 48행, TC-LNK-003 |
| B-2 | DDC 제어와 capabilities 기반 구성 | DDC/CI를 지원하는 모니터 | `tbdctl ddc external probe`, `caps`, `plan`, 밝기 탭의 DDC 구역, 결합 밝기, 밝기 동기화의 DDC 대상 | TC-DDC-003, TC-DDC-005 |
| B-3 | DSC 사용 모드, DSC 전환, PPS 필드 | DSC를 지원하는 디스플레이 (예: 4K 144 Hz 이상 또는 5K 이상 DisplayPort 모니터) | `tbdctl dsc`, `signal`로 DSC 사용 색 모드 실측. DSC 활성 상태에서 프레임버퍼 노드와 DPCD(0x160 이후)를 비교해 PPS 자료 출처 탐색 | 46행, TC-COL-007 |
| B-4 | 언더스캔 조회와 변경 | 언더스캔을 지원하는 디스플레이 | `tbdctl arrangement`, 배치 탭 | TC-ARR-005 |
| B-5 | HDR 선언 추가의 대상 효과 | HDR을 선언하지 않았지만 PQ 입력을 처리하는 디스플레이 | A-1과 같은 절차를 해당 디스플레이에 적용 | 13행 |
| B-6 | 수치의 절대 정확도 | 휘도계 또는 측색기 | 내장 패널 휘도 값, 채도 조정, XDR 밝기 업스케일의 화면 측정 | `docs/ROADMAP.md` 5절 (6), (15), (23) |

그 밖에 장비가 있으면 확인할 것: 충전을 제한하는 3 A 케이블, 제조사 ID와 인증 ID를 갖춘 케이블, 액티브 케이블, macOS 15 기기.

## 4. (다) 조사 뒤 판단

| 번호 | 항목 | 현재 상태 | 조사할 것 | 판단 기준 |
| --- | --- | --- | --- | --- |
| C-1 | 네이티브와 기본 해상도 override, 디스플레이 역할 변경 (5행) | 오버라이드 파일의 해당 키가 Apple Silicon에서 동작한다는 근거 없음 | `/System/Library/Displays/Contents/Resources/Overrides/`의 Apple 제공 파일에 쓰인 키 조사, 참고 제품의 안내 문서(조사 문서 G19) 대조, 관리자 인증으로 키를 넣어 재초기화 뒤 모드 목록 변화 실측 | 키 하나라도 실측으로 동작하면 구현. 동작하지 않으면 제외로 결정 |
| C-2 | DSC PPS 필드 (46행) | PPS를 얻는 API와 레지스트리 속성 미확인 | B-3 장비로 DSC 활성 상태의 레지스트리 전체 비교 | 자료 출처가 있으면 구현. 없으면 필요 대역폭 추정만 유지하고 제외로 결정 |
| C-3 | 색 관리를 거치지 않는 출력의 채도 | 채도 조정은 색 프로파일 방식이라 색 관리를 거치는 내용에만 적용 | HDR 내용과 색 관리 밖 출력에서의 효과 실측 (B-6 장비) | 효과가 없으면 문서에 제약으로 명시 |

## 5. (라) 제외 결정 유지

다시 시도하지 않음. 포함하려면 사용자의 명시적 결정 필요.

| 번호 | 항목 | 이유 | 기록 |
| --- | --- | --- | --- |
| D-1 | 8K 초과 가상 디스플레이 (40행) | 백킹 16384 x 8640 요청에서 WindowServer가 중단되어 로그인 세션 종료. 프레임버퍼가 보고하는 최대 소스 크기도 7680 x 4320 | E-12 |
| D-2 | EDID 장치 쓰기 (44행) | 디스플레이 저장 장치 손상 위험. 가상 EDID(재시동 시 소멸)로 대체 | E-10 |
| D-3 | DSC 강제 | DSC 설정 전용 API 부재. 시스템이 색 모드로 제공하는 범위의 전환만 제공 | MRD-EXC-006 |

## 6. (마) 대조표 밖의 참고 제품 기능

참고 제품(BetterDisplay) 저장소의 2026-11 기준 기능 목록과 대조. 대조표 58행은 조사 시점의 총괄표 기준이라 아래 항목은 포함되지 않음.

| 번호 | 기능 | 현재 처리 | 망라에 포함할 경우의 작업 |
| --- | --- | --- | --- |
| E-1 | 화면 스트리밍, PIP, 선택한 창 스트리밍 | 제외 (MRD-EXC-003: 디스플레이 옵션 설정 범위 밖) | ScreenCaptureKit 기반 캡처와 표시 창. 별도 기능군 |
| E-2 | 키보드 밝기 키 가로채기, 사용자 정의 OSD, 단축키 | 제외 (MRD-EXC-005: 상주 프로세스 필요, MRD-EXC-001과 충돌) | 상주 보조 프로세스 또는 창이 떠 있는 동안만 동작하는 단축키. 창 앱 요구와의 절충 결정 필요 |
| E-3 | HDMI-CEC 제어 | 미조사 | CEC 전송 경로(IOAVService 또는 어댑터) 조사, CEC 지원 TV에서 실측 |
| E-4 | 네트워크 장치 제어 (TV 등) | 미조사 | 제조사별 네트워크 프로토콜 조사. 외부 통신이 생기므로 범위 결정 필요 |
| E-5 | 사용자 정의 3D LUT | 미구현 | 색 프로파일에 LUT 태그를 넣는 방식 조사 (채도 조정의 ICC 편집 확장) |
| E-6 | 고급 이미지 조정 (조사 시점 이후 추가) | 일부 대응 (감마, 대비, 색온도, 게인, 채도) | 참고 제품의 항목을 다시 조사해 빠진 조정 확인 |
| E-7 | 디스플레이 그룹 | 일부 대응 (밝기 동기화) | 여러 디스플레이를 묶어 같은 설정을 적용하는 그룹 모델 |
| E-8 | 소프트웨어 오디오 조정 | 범위 밖 (디스플레이 옵션 아님) | DDC 볼륨은 제공. 소프트웨어 볼륨은 오디오 장치 제어라 별도 판단 |
| E-9 | 통합과 스크립팅 (URL 방식, HTTP, 알림) | 일부 대응 (`tbdctl`과 `--json`) | URL 방식 등록과 앱 실행 중 원격 제어 |
| E-10 | 내장 콘솔 | 일부 대응 (이벤트 기록, 진단 보고서) | 앱 안의 명령 입력 화면 |
| E-11 | 다국어 | 한국어만 제공 | 문자열 분리와 번역 |

- E-1, E-2는 명세에서 제외로 결정한 항목. E-3부터 E-11은 범위에 넣을지 결정이 필요한 항목
- 참고 제품의 세부 설정 키(조사 문서 `docs/research/competitors.md` 3절)까지 대조하려면 대조표를 설정 키 단위로 다시 작성해야 함

## 7. 권장 순서

- (1) A-1, A-2: 다음에 자리에 있을 때 바로 실행. 13행이 구현으로 바뀌면 부분 3행
- (2) C-1: 관리자 인증 1-2회로 결론 가능. 결과에 따라 5행을 구현 또는 제외로 정리
- (3) B-2, B-1, B-3 순서: 장비를 구할 수 있는 순서대로. DDC 모니터가 가장 구하기 쉬움
- (4) 6절의 범위 결정: E-3부터 E-11 중 포함할 항목을 정하면 대조표에 행을 추가하고 요구사항부터 작성
- (5) (라)는 유지

## 8. 완료 판정

- 대조표의 모든 행이 구현 또는 제외(사유 기록)로 정리됨
- 보류와 미실행 TC가 0건이거나, 남은 건이 모두 제외 결정에 대응
- 6절의 항목마다 포함 또는 제외 결정이 `docs/ROADMAP.md` 4절에 기록됨
