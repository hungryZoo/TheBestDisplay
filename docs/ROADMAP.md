# ROADMAP: TheBestDisplay 개발 계획

- 진행 방식: 작업 항목 1개당 1턴. 턴마다 개발, 문서 대조와 갱신, 검증, 커밋의 4단계 파이프라인 수행
- 커밋 규칙: 항목 1개당 커밋 1건. 작업 브랜치 `develop`. 원격 push와 `main` 병합은 사용자 승인 후
- 검증 규칙: 해당 항목 TC와 영향 범위 테스트 실행. 미실행 TC는 미실행으로 유지

## 1. 단계별 완료 조건

| 단계 | 내용 | 완료 조건 |
| --- | --- | --- |
| P0 | 조사, 선행 실험, 명세 | MRD, PRD, SRS, TC, ADR 작성. 추적성 검사 오류와 경고 0건 |
| P1 | 기반 | 창 앱과 CLI 실행. 디스플레이 목록, 정보, EDID 해석 표시. P1 TC 통과 |
| P2 | 모드와 신호 | 모드, 색 모드, HDR의 조회와 전환. 자동 복귀 동작. P2 TC 통과 |
| P3 | 진단 | 링크, 포트, 연결 경로, 진단 규칙, 이벤트, 보고서. P3 TC 통과 |
| P4 | 조정 | 밝기, DDC, 색 조정, 배치. P4 TC 통과 (장비 의존 TC는 보류 표기) |
| P5 | 확장 | 가상 디스플레이, HiDPI 스케일링, 프로파일, 문서 마감. 전체 TC 실행 |
| P6 | 제외 범위 축소 | DSC 전환, EDID 오버라이드, 사용자 정의 타이밍, 사용자 정의 스케일 해상도, 링크 제어. 장비 의존 TC는 보류 또는 미실행 표기 |

- TC 밖 미검증 사항
  - (1) DSC 사용 모드의 표시: DSC 지원 싱크 미보유 (U-04). 판정 로직은 픽스처 단위 테스트로만 확인
  - (2) 프로파일 적용의 색 모드, HDR, 회전 단계: 단위 테스트로만 확인. 모드와 배치 단계는 가상 디스플레이로 실측 (TC-PRF-002)
  - (3) SkyLight 직접 호출 경로의 미출력 원인: 미확인. 기본 경로에서 제외한 상태 유지 (ADR-0005)
  - (4) CIO `CableSpeed`와 `CableGeneration` 값의 의미, HDMI FRL 링크 데이터 배치: 미확인. 원시 값 표시
  - (5) macOS 15에서의 동작: 미검증. 검증은 macOS 26.5.2에서만 수행 (E-01)
  - (6) XDR 밝기 업스케일의 화면 밝기: 전달 테이블과 EDR 헤드룸 측정값으로만 확인. 육안 확인 미수행
  - (7) EDID 오버라이드 구역의 화면 표시: 외장 디스플레이에서만 나타나 미확인. 그 밖의 새 구역(주사율 측정, 사용자 정의 스케일 해상도, DSC 버튼, XDR 업스케일, 구성 보호)은 내장 디스플레이 화면에서 표시 확인
  - (8) 구성 보호의 색 모드, HDR, 회전, 미러 복원: 차이 산출 단위 테스트로만 확인. 모드 복원은 가상 디스플레이로 실측 (TC-PRF-004)
  - (9) 밝기 동기화의 DDC와 시스템 밝기 제어 대상, 밝기 동기화 구역의 화면 표시(디스플레이 2대 이상일 때만 나타남): 미확인
  - (10) 전원 어댑터 연결 상태의 값, 외장 디스플레이의 HDCP 능력 값, PHY 레인의 실기기 연결 상태 값: 미검증 (PHY는 실측 픽스처로 확인)
  - (11) 해상도 슬라이더를 움직여 전환하는 동작: 유일한 온라인 디스플레이라 미실행
- 원격 저장소 push와 `main` 병합: 미수행 (U-05)
