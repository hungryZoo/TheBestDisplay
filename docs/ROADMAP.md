# ROADMAP: TheBestDisplay 개발 계획

- 진행 방식: 작업 항목 1개당 1턴. 턴마다 개발, 문서 대조와 갱신, 검증, 커밋의 4단계 파이프라인 수행
- 커밋 규칙: 항목 1개당 커밋 1건. 작업 브랜치 `develop`. 원격 push와 `main` 병합은 사용자 승인 후
- 검증 규칙: 해당 항목 TC와 영향 범위 테스트 실행. 미실행 TC는 미실행으로 유지

## 1. 단계별 완료 조건

| 단계 | 내용 | 완료 조건 |
| --- | --- | --- |
| P0 | 조사, 선행 실험, 명세 | MRD, PRD, SRS, TC, ADR 작성. 추적성 검사 오류와 경고 0건 |
| P1 | 기반 | 창 앱과 CLI 실행. 디스플레이 목록, 정보, EDID 해석 표시. P1 TC 통과 |
| P2 | 모드와 신호 | 모드, 색 모드, HDR의 조회와 전환. 자동 복귀 동작. P2 TC 통과 |
| P3 | 진단 | 링크, 포트, 연결 경로, 진단 규칙, 이벤트, 보고서. P3 TC 통과 |
| P4 | 조정 | 밝기, DDC, 색 조정, 배치. P4 TC 통과 (장비 의존 TC는 보류 표기) |
| P5 | 확장 | 가상 디스플레이, HiDPI 스케일링, 프로파일, 문서 마감. 전체 TC 실행 |

## 3. 사용자 참여 항목

| 항목 | 내용 | 시점 |
| --- | --- | --- |
| U-01 | 화면 변경 TC(모드, 색 모드, HDR, 회전, 미러, 연결 해제) 실행 중 화면 깜박임과 일시적 해상도 변화 발생. 각 TC는 자동 복귀로 원상 복구 | T04-T06, T12 |
| U-02 | HDMI 직결 구성에서 링크 정보 확인 | T07 이후 |
| U-03 | DDC 지원 모니터에서 DDC 제어 확인 | T10 이후 |
| U-04 | DSC 지원 모니터에서 DSC 사용 모드 확인 | T05 이후 |
| U-05 | 원격 저장소 생성과 push 승인 | 임의 시점 |

- goal 지시에 따라 권장안으로 진행하고 기록. 변경 요청 시 관련 문서 동시 갱신
