# PRD: TheBestDisplay 기능 요구 문서

- 상위 문서: `docs/MRD.md`
- 단계 표기: P1 기반, P2 모드와 신호, P3 진단, P4 조정, P5 확장
- 우선순위 표기: 필수, 권장

## 1. 워크플로

### 1.1 설정 변경 (4단계 파이프라인)

- (1) 사이드바에서 디스플레이 선택
- (2) 기능 탭에서 항목 선택 (예: 색 모드 탭의 RGB 8 bpc)
- (3) 적용 후 확인 대화상자 표시와 제한 시간 카운트다운
- (4) 확인 시 확정, 미확인 또는 취소 시 이전 상태 복귀

### 1.2 연결 진단 (3단계 파이프라인)

- (1) 사이드바의 연결 진단 선택
- (2) 포트별 연결 경로와 점검 단계 결과 확인
- (3) 발견 항목의 사유, 근거 수치, 조치 안내 확인 후 필요 시 보고서 내보내기

## 2. 화면 구성

| 화면 | 위치 | 내용 |
| --- | --- | --- |
| 사이드바 | 창 왼쪽 | 디스플레이 목록(이름, 내장 또는 외장, 해상도와 주사율 요약), 가상 디스플레이, 연결 진단, 프로파일 |
| 개요 탭 | 디스플레이 상세 | 제품 정보, 현재 모드와 신호 요약, 싱크 능력 요약, EDID 해석과 원본, EDID 오버라이드(외장) |
| 해상도 탭 | 디스플레이 상세 | 전체 모드 목록, 필터, 주사율 선택, HiDPI 스케일링 |
| 색 모드 탭 | 디스플레이 상세 | 현재 신호 형식, 색 모드 목록, DSC 표시, HDR 전환과 정보, 타이밍 목록 |
| 링크 탭 | 디스플레이 상세 | 링크 속도, 레인, 대역폭 사용률, DSC와 FEC 상태, DPCD 정보, 연결 경로 |
| 밝기 탭 | 디스플레이 상세 | 밝기, DDC 기능(대비, 볼륨, 입력, 전원), 임의 VCP |
| 색 조정 탭 | 디스플레이 상세 | 색 프로파일, 감마, 색온도, 게인, Night Shift, True Tone |
| 배치 탭 | 디스플레이 상세 | 회전, 미러, 메인 지정, 위치 편집, 연결 해제, 언더스캔 |
| 연결 진단 | 사이드바 항목 | 포트 목록, 연결 경로, 점검 단계, 발견 항목, 이벤트 기록, 보고서 내보내기 |
| 프로파일 | 사이드바 항목 | 프로파일 목록, 저장, 적용, 이름 변경, 삭제 |

## 3. 상태 전이: 자동 복귀 안전장치

| 현재 상태 | 이벤트 | 다음 상태 | 동작 |
| --- | --- | --- | --- |
| 대기 | 변경 요청 | 적용 중 | 변경 전 상태 저장, 복귀 정보 파일 기록, 변경 적용 |
| 적용 중 | 적용 성공 | 확인 대기 | 확인 대화상자 표시, 타이머 시작 (기본 15초) |
| 적용 중 | 적용 실패 | 대기 | 오류 코드와 사유 표시, 복귀 정보 파일 삭제 |
| 확인 대기 | 사용자 확인 | 대기 | 변경 확정, 복귀 정보 파일 삭제 |
| 확인 대기 | 사용자 취소 | 복귀 중 | 변경 전 상태 적용 |
| 확인 대기 | 타이머 만료 | 복귀 중 | 변경 전 상태 적용 |
| 확인 대기 | 대상 디스플레이 연결 해제 | 대기 | 타이머 중단, 복귀 정보 파일 유지 |
| 복귀 중 | 복귀 성공 | 대기 | 복귀 완료 표시, 복귀 정보 파일 삭제 |
| 복귀 중 | 복귀 실패 | 대기 | 오류 표시, 복귀 정보 파일 유지 |

- 확인 대기 중 새 변경 요청은 거부
- 복귀 정보 파일이 남은 상태로 앱 실행 시 복귀 제안 표시

## 5. 명령행 도구

| 명령 | 내용 |
| --- | --- |
| `tbdctl list` | 디스플레이 목록 |
| `tbdctl capabilities` | 기능별 가용성과 누락 심볼 |
| `tbdctl info <디스플레이> [--edid-out <경로>] [--hex]` | 제품 정보, 싱크 능력, EDID 해석. EDID 원본 저장과 16진 표시 |
| `tbdctl modes <디스플레이> [--hidpi] [--outside-default]` | 전체 모드 목록. HiDPI만, 시스템 설정 목록 밖만 필터 |
| `tbdctl set-mode <디스플레이> <모드> [--timeout <초>] [--yes] [--method <경로>]` | 모드 전환. 모드 형식은 `<폭>x<높이>[@<주사율>][:hidpi\|:lodpi]` 또는 `mode:<번호>`. Return 입력 시 확정, 제한 시간 내 입력이 없으면 복귀. `--yes`는 즉시 확정 |
| `tbdctl scaled <디스플레이> [list \| add <폭>x<높이> \| remove <폭>x<높이>]` | 사용자 정의 스케일 해상도(HiDPI 논리 해상도) 조회, 추가, 삭제. 쓰기 권한이 없으면 관리자 권한으로 실행할 명령 출력 |
| `tbdctl align <디스플레이> <기준 디스플레이> <위치>` | 기준 디스플레이 대비 16방향 정렬. 위치는 `left-top`, `right-center`, `bottom-right`, `corner-top-left` 등 |
| `tbdctl auto-disconnect [on\|off]` | 내장 자동 연결 해제 설정 조회와 변경. 해제와 재연결은 창 앱이 수행 |
| `tbdctl favorites <디스플레이> [list \| add [<모드>] \| remove [<모드>]]` | 즐겨찾기 모드 조회, 추가, 삭제. 모드를 생략하면 현재 모드 |
| `tbdctl notch <디스플레이> [show\|hide] [--timeout <초>] [--yes]` | notch 영역 사용 여부 조회와 전환 |
| `tbdctl refresh <디스플레이> [--seconds <초>]` | 주사율 측정 (기본 2초) |
| `tbdctl revert-pending [--discard]` | 확인 없이 종료된 변경의 복귀 또는 복귀 정보 삭제 |
| `tbdctl signal <디스플레이> [--timings]` | 현재 송출 신호, 색 모드 목록, DSC 판정. `--timings`는 싱크 타이밍 전체 |
| `tbdctl set-color <디스플레이> <색 모드> [--timeout <초>] [--yes]` | 색 모드 전환. 형식은 `id:<번호>` 또는 `<rgb\|ycbcr444\|ycbcr422\|ycbcr420>[:<bpc>][:<full\|limited>][:<sdr\|pq\|hlg>]`. 생략 항목은 현재 값 우선 |
| `tbdctl set-timing <디스플레이> <타이밍> [--timeout <초>] [--yes]` | 연결 수준 타이밍 직접 선택. 형식은 `id:<번호>` 또는 `<폭>x<높이>@<주사율>`. 목록은 `tbdctl signal --timings` |
| `tbdctl dither <디스플레이> [on\|off]` | GPU 디더링 조회와 전환 |
| `tbdctl link <디스플레이>` | 링크 속도, 레인, 대역폭 사용률, 색 형식별 필요 대역폭과 선택 불가 사유, DPCD, 링크 훈련 결과 |
| `tbdctl ports` | 포트별 지원 전송, 케이블 e-marker, 독, 영상 링크, 디스플레이까지의 연결 경로와 단계별 상태 |
| `tbdctl diagnose` | 포트별 점검 단계와 진단 발견 항목(근거, 조치) |
| `tbdctl report <경로> [--redact] [--text]` | 진단 보고서 저장. 기본 JSON, `--text`는 텍스트, `--redact`는 일련번호 가림 |
| `tbdctl hdr <디스플레이> [on\|off] [--timeout <초>] [--yes]` | HDR 상태와 정보 조회, 켜기와 끄기 |
| `tbdctl dsc <디스플레이> [on\|off] [--timeout <초>] [--yes]` | DSC 상태와 전환 가능 여부 조회, 켜기와 끄기 |
| `tbdctl edid <디스플레이> check [<파일>]` | EDID 구조 검증과 능력 요약. 파일 또는 현재 디스플레이의 EDID 대상 |
| `tbdctl edid <디스플레이> i2c [--out <파일>]` | I2C로 EDID를 직접 읽어 검증하고 시스템 제공 EDID와 비교 |
| `tbdctl edid <디스플레이> patch <편집 목록> [--in <파일>] [--out <파일>] [--apply] [--timeout <초>] [--yes]` | EDID 편집. 편집 목록은 쉼표로 이은 `remove-dsc`, `remove-hdr`, `remove-ycbcr`, `remove-420`, `remove-vrr`, `limit-frl:<0-6>`, `limit-tmds:<MHz>`. `--apply`는 편집본을 가상 EDID로 적용 |
| `tbdctl edid <디스플레이> timing <타이밍> [--preferred] [--in <파일>] [--out <파일>] [--apply] [--timeout <초>] [--yes]` | 사용자 정의 타이밍 계산과 EDID 추가. 형식은 `<폭>x<높이>@<주사율>[:rb\|:rb2]` 또는 `raw:<수평 활성>,<프런트 포치>,<동기>,<백 포치>,<수직 활성>,<프런트 포치>,<동기>,<백 포치>,<픽셀 클록 kHz>[,+h\|-h][,+v\|-v]` |
| `tbdctl edid <디스플레이> apply <파일> [--timeout <초>] [--yes]` | EDID 파일을 가상 EDID로 적용 |
| `tbdctl edid <디스플레이> reset` | 가상 EDID 해제 (원본 EDID 복귀) |
| `tbdctl redetect` | 디스플레이 재감지 요청 |
| `tbdctl brightness <디스플레이> [0-100]` | 밝기 조회와 설정. 시스템 밝기 제어 또는 DDC. 소프트웨어 디밍은 창 앱 전용 |
| `tbdctl xdr <디스플레이> [<배율 %>] [--seconds <초>]` | XDR 밝기 업스케일 가능 여부와 EDR 헤드룸 조회. 배율(100-200)을 주면 지정 시간(기본 10초) 동안 적용한 뒤 해제 |
| `tbdctl brightness-sync <원본 디스플레이> [--seconds <초>]` | 원본의 밝기를 다른 디스플레이에 동기화 (기본 30초 동안) |
| `tbdctl overlay-dim <디스플레이> <강도 %> [--seconds <초>]` | 오버레이 방식 디밍을 지정 시간(기본 10초) 동안 적용 |
| `tbdctl preset <디스플레이> [<번호 또는 이름>] [--timeout <초>] [--yes]` | 디스플레이 프리셋 조회와 전환 |
| `tbdctl night-shift [on\|off]` | 시스템 Night Shift 조회와 전환 |
| `tbdctl night-shift-sync <디스플레이> [--seconds <초>]` | Night Shift 상태에 맞춘 색온도를 대상 디스플레이에 적용 (기본 30초 동안) |
| `tbdctl hdr-profile <디스플레이> [sdr\|hdr <프로파일\|none> \| apply]` | SDR과 HDR 상태별 색 프로파일 지정, 조회, 현재 상태에 맞춘 1회 적용 |
| `tbdctl ddc <디스플레이> probe \| get <코드> \| set <코드> <값>` | DDC 탐지, VCP 읽기와 쓰기. 코드는 이름(brightness, contrast, volume, mute, input, power) 또는 숫자 |
| `tbdctl color <디스플레이> [--profiles] [--set <프로파일 이름 또는 경로>]` | 색 프로파일 조회와 지정, Night Shift, True Tone 상태 |
| `tbdctl arrangement` | 디스플레이별 위치, 크기, 회전, 미러 상태 조회 |
| `tbdctl rotate <디스플레이> <0\|90\|180\|270> [--timeout <초>] [--yes]` | 회전 |
| `tbdctl mirror <디스플레이> <원본\|off> [--timeout <초>] [--yes]` | 미러 설정과 해제 |
| `tbdctl main <디스플레이>`, `tbdctl move <디스플레이> <x> <y>` | 메인 디스플레이 지정, 위치 지정 |
| `tbdctl disconnect <디스플레이> [--timeout <초>] [--yes]`, `tbdctl reconnect [<ID>]` | 논리적 연결 해제와 재연결 |
| `tbdctl virtual <폭>x<높이> [--hidpi] [--name <이름>] [--seconds <초>]` | 가상 디스플레이를 만들고 지정 시간 동안 유지한 뒤 삭제 |
| `tbdctl profile list \| show <이름> \| save <이름> [--replace] \| apply <이름> [--timeout <초>] [--yes] \| rename <이름> <새 이름> \| delete <이름>` | 구성 프로파일 저장, 조회, 적용, 이름 변경, 삭제 |
| `tbdctl profile check <이름>` | 프로파일과 현재 구성의 차이 조회. 차이가 있으면 종료 코드 1 |
| `tbdctl profile protect <이름>`, `profile unprotect`, `profile protection` | 구성 보호 설정, 해제, 상태 조회. 복원은 창 앱 실행 중에 수행 |

- 공통 옵션: `--json`
- 디스플레이 지정자: 1부터 시작하는 순번, `id:<디스플레이 ID>`, `main`, `builtin`, `external`, 이름 일부
- 종료 코드: 0 성공, 1 실행 실패, 2 사용법 오류, 3 미지원 기능 또는 대상 없음

## 6. 요구사항

### 6.1 앱 구조 (APP)

### 6.2 디스플레이 정보 (INF)

| ID | 요구사항 | 단계 | 우선순위 | MRD 근거 |
| --- | --- | --- | --- | --- |
| PRD-INF-001 | 제품명, 제조사, 제조 연도, 일련번호, 디스플레이 ID, UUID, 내장 여부, 물리 크기, 대각 인치, PPI, 원본 해상도 표시 | P1 | 필수 | MRD-SCP-002 |
