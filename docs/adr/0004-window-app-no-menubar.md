# ADR-0004: 메뉴 막대 상주 없는 단일 창 앱

- 상태: 채택
- 관련: PRD-APP-001, SRS-UI-002, MRD-EXC-001, MRD-EXC-005, MRD-DIF-001

## 맥락

- 지시서의 요구: 메뉴 막대가 아닌 창 실행 프로그램
- 가상 디스플레이, 소프트웨어 디밍, 전달 테이블 조정은 프로세스 수명에 종속

## 결정

- 단일 창 앱. `NSStatusItem` 미사용. 마지막 창 닫기 시 종료
- 프로세스 수명 종속 기능(가상 디스플레이, HiDPI 스케일링, 소프트웨어 디밍, 색 조정)은 앱 실행 중에만 유지. 해당 화면에 이 제약을 표시
- 종료 시 전달 테이블 초기화, 미러 해제, 가상 디스플레이 삭제 수행
- 시스템이 영속 저장하는 설정(모드, 색 모드, HDR, 회전, 배치, 색 프로파일, DDC 값)은 종료 후에도 유지

## 근거

- 지시서 요구 충족
- 상주 프로세스 없음으로 자원 사용과 권한 요구 축소

## 결과

- 키보드 밝기 키 연동과 OSD 제외
- 프로세스 수명 종속 기능의 상시 유지가 필요한 사용자는 창을 열어 둔 상태로 사용

## 대안

- 메뉴 막대 상주: 지시서 요구와 불일치
- 로그인 항목 백그라운드 도우미: 구조 복잡도 증가. 요구 발생 시 재검토
