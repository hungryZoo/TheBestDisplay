# ADR-0003: 화면 변경 동작의 자동 복귀 안전장치

- 상태: 채택
- 관련: PRD-SAF-001, PRD-SAF-002, SRS-SAF-001, SRS-SAF-002, MRD-RSK-002, E-04

## 맥락

- 숨은 모드, 색 모드, HDR, 회전 전환은 싱크가 수용하지 못하면 화면 미출력 유발
- 화면이 나오지 않는 상태에서는 사용자가 앱을 조작해 되돌리기 불가

## 결정

- 화면 변경 동작 전체를 `RevertGuard` 경유로 수행
- 적용 전 상태 저장, 적용 후 확인 대화상자와 15초 타이머, 미확인 시 이전 상태 복귀
- 변경 전 상태를 디스크에 기록하고 확인 시 삭제. 다음 실행 시 파일이 남아 있으면 복귀 제안
- 상태 기계는 TBDCore에 두고 시계와 적용기를 주입

## 근거

- 시스템 설정의 해상도 변경 확인 방식과 같은 사용 경험
- 상태 기계의 순수 로직 분리로 하드웨어 없이 전이 전체 테스트 가능

## 결과

- 화면 변경 기능 추가 시 `DisplayApplying`의 상태 저장과 복원 구현 필수
- 확인 대기 중 다른 변경 요청 거부

## 대안

- 복귀 없음: 미출력 시 복구 수단 부재
- 단축키 복귀만 제공: 사용자가 단축키를 모르면 복구 불가
