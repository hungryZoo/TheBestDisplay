# MRD: TheBestDisplay 시장 요구 문서

- 제품: TheBestDisplay — macOS 디스플레이 설정 및 연결 진단 창 앱
- 작성 기준: 사용자 지시서(goal), 경쟁 제품 조사(`docs/research/competitors.md`), 플랫폼 API 조사(`docs/research/platform-apis.md`), 선행 실험(`docs/research/spikes.md`)

## 1. 배경

- macOS 시스템 설정의 디스플레이 패널은 해상도, 주사율, HDR, 색 프로파일, 회전, 배치만 노출
- 픽셀 인코딩(RGB, YCbCr), 비트 심도, 레인지, DSC 사용 여부, 링크 속도, 레인 수는 시스템 설정에 표시되지 않으며 선택 불가
- 화면이 켜지지 않거나 원하는 모드(예: 4K 120 Hz RGB 10 bpc)가 목록에 없을 때 원인(케이블, 포트, 독, 싱크 능력, 대역폭) 확인 수단 부재
- BetterDisplay는 설정 기능이 넓으나 메뉴 막대 앱이며 연결 진단 기능이 제한적. WhatCable은 USB-C 케이블과 포트 진단에 한정되며 디스플레이 설정 기능 없음

## 2. 문제 정의

| ID | 내용 |
| --- | --- |
| MRD-PRB-001 | 시스템 설정이 숨기는 디스플레이 모드(HiDPI 변형, 저해상도, 전체 주사율)를 선택할 방법 부재 |
| MRD-PRB-002 | 출력 신호 형식(픽셀 인코딩, 비트 심도, 레인지, EOTF, DSC)의 확인과 선택 방법 부재 |
| MRD-PRB-003 | 링크 상태(속도, 레인, 터널링, HPD, 케이블 등급)의 확인 방법 부재 |
| MRD-PRB-004 | 화면 미출력 또는 원하는 모드 선택 불가 시 원인 설명 부재 |
| MRD-PRB-005 | 디스플레이 관련 설정(밝기, DDC, 색, 배치, 회전, 미러, 가상 디스플레이)이 여러 도구에 분산 |

## 3. 대상 사용자

| ID | 내용 |
| --- | --- |
| MRD-USR-001 | 외장 모니터나 TV를 Apple Silicon Mac에 연결해 쓰는 사용자. 해상도, 주사율, HDR, 색 형식을 직접 통제하려는 요구 |
| MRD-USR-002 | 독, 허브, 케이블 조합에서 화면 미출력이나 모드 제한을 겪는 사용자. 원인 확인 요구 |
| MRD-USR-003 | 디스플레이 구성을 자주 바꾸는 개발자와 영상 작업자. 구성 저장과 복원, 명령행 제어 요구 |

## 4. 경쟁 분석 요약

| 제품 | 형태 | 강점 | 한계 |
| --- | --- | --- | --- |
| macOS 시스템 설정 | 설정 패널 | 안정성, 공식 지원 | 신호 형식과 링크 정보 미노출, 숨은 모드 접근 제한 |
| BetterDisplay | 메뉴 막대 앱, CLI | HiDPI 스케일링, 가상 디스플레이, DDC, XDR 밝기, 색 모드 선택 등 설정 범위 최대 | 메뉴 막대 중심 구조, 연결 실패 원인 설명 기능 제한, 주요 기능 유료 |
| WhatCable | 메뉴 막대 앱, CLI | USB-C 케이블과 포트 능력의 평문 설명 | 디스플레이 설정 기능 없음, 디스플레이 신호 형식 진단 범위 밖 |
| MonitorControl | 메뉴 막대 앱 | DDC 밝기와 볼륨, 키보드 연동 | 해상도, 색 형식, 진단 기능 없음 |
| Lunar | 메뉴 막대 앱 | 적응형 밝기, XDR, DDC | 유료, 진단 기능 제한 |
| displayplacer | CLI | 해상도, 배치, 회전의 스크립트 제어 | GUI 없음, 신호 형식과 진단 없음 |
| SwitchResX | 설정 패널 | 사용자 정의 해상도 | Apple Silicon에서 사용자 정의 타이밍 제약 |

- 상세 기능 목록과 출처는 `docs/research/competitors.md`

## 5. 사용 시나리오

| ID | 내용 |
| --- | --- |
| MRD-SCN-001 | 사용자가 4K TV를 연결했으나 색이 뭉개져 보임. 앱에서 현재 신호가 YCbCr 4:2:2임을 확인하고 RGB 모드 목록과 각 모드의 선택 불가 사유(대역폭 초과, DSC 미지원)를 확인한 뒤 RGB 8 bpc 120 Hz 또는 RGB 10 bpc 60 Hz로 전환 |
| MRD-SCN-002 | 사용자가 독에 모니터를 연결했으나 화면 미출력. 앱의 진단 화면에서 포트별 상태(HPD 미감지, 링크 훈련 실패, 케이블 등급 부족 등)와 조치 안내 확인 |
| MRD-SCN-003 | 사용자가 4K 모니터에서 2560x1440 HiDPI를 원하나 시스템 설정 목록에 없음. 앱의 전체 모드 목록에서 선택하거나 가상 디스플레이 기반 HiDPI 스케일링으로 적용 |
| MRD-SCN-004 | 사용자가 모드 전환 후 화면이 표시되지 않음. 확인 입력이 없으면 제한 시간 뒤 이전 설정으로 자동 복귀 |
| MRD-SCN-005 | 사용자가 외장 모니터의 밝기, 대비, 볼륨, 입력을 앱에서 DDC로 조절 |
| MRD-SCN-006 | 사용자가 재택과 사무실 구성(해상도, 배치, 색 모드, HDR)을 프로파일로 저장하고 한 번에 복원 |
| MRD-SCN-007 | 사용자가 문제 상황의 진단 보고서를 파일로 내보내 공유 |
